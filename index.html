1. Agrega tu ramo

Desde "Mis ramos", presiona "+ Agregar ramo" y escribe el nombre de la asignatura que quieres registrar.

Luego indica si el ramo tiene laboratorio y, si corresponde, define qué porcentaje corresponde a teoría y cuál a laboratorio.

2. Configura tus evaluaciones

Agrega cada prueba, control, tarea, laboratorio o evaluación que forme parte de tu ramo.

Para cada evaluación puedes indicar su nota y la ponderación que representa dentro del ramo. Si todavía no tienes la nota, puedes dejarla como pendiente.

Si una evaluación está formada por varias notas, también puedes agregar subnotas y definir cuánto pesa cada una.

3. Revisa tu promedio

Una vez guardado el ramo, podrás ver tu promedio actual y consultar todas las evaluaciones registradas.

Cuando agregues nuevas notas, podrás volver al ramo para revisar cómo cambia tu promedio.

4. Calcula qué necesitas

La calculadora te permite establecer un objetivo, como la nota mínima para aprobar u otro promedio que quieras alcanzar.

También puedes revisar qué nota necesitarías en una evaluación pendiente para acercarte a ese objetivo.

5. Usa las herramientas adicionales

Si tu ramo contempla una PAR o un examen, podrás utilizar estas secciones para estimar qué resultado necesitas.

Estas herramientas son orientativas y dependen de las ponderaciones que hayas configurado para tu ramo.
